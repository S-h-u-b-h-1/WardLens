HOW WARDLENS WORKS

Three simple steps.

Explore the full process without a microphone, account, or real location.

01

Understand the report

WardLens reads a reviewed statement in Hindi, Bengali, Hinglish or English. The public WardLens workspace can transcribe consented voice with Gnani Prisma.

02

Look for possible links

It compares issues, service areas and available time evidence—without guessing a verified root cause.

03

Inspect the source

Click a report or dashed link to see the exact quotation, the reasons for the suggestion and any counter-evidence.

What if a link is wrong?

Rejecting a possible relationship in this browser-only showcase removes it from the local candidate count. It doesn't write any data or change the original sources.

No live model calls

This static site never requests microphone permission or accesses Gnani. The public WardLens workspace has separate, consent-gated Prisma transcription; this fictional tutorial makes no provider calls.

WardLens proposes questions worth investigating. It does not establish a root cause, confirm a person's identity, or notify any civic authority.
