Location not working? Fix iPhone permissions

Open WardLens directly in Safari or Chrome—not inside WhatsApp, LinkedIn or another app.

iPhone Settings → Privacy & Security → Location Services: turn Location Services on. Select Safari Websites or Chrome, allow location while using the browser, and enable Precise Location.

In Safari, open this website's page menu → Website Settings → Location → Allow or Ask. Return here and tap Use my location.

THE WARDLENS METHOD / 03

The source stays in the picture.

Good investigation begins with the observation—not a conclusion. WardLens helps you compare nearby reports while keeping uncertainty visible.
